# How to use/install mods for Marvel Rivals 
- Please note: This is for PC (Mostly Windows Desktops) only, mods are not available on console (as of May 2026)
- I also do have useful configs here (do not use the configs until there is a fix as there have been a few reported account issues/suspensions due to configs but not mods)
- If there is an 'unverified download' that appears when you try to download it it is completely safe and open source
- You can also download the necessary setup tools here
  - [UTOC Signature Bypass - NexusMods](https://www.nexusmods.com/marvelrivals/mods/2940)
- Please Note: I have my Marvel Rivals game files on my C drive, but the letter/location may change depeding on where you installed it/how many drives you have
- Lastly, I am not responsible for any bans/suspensions caused by using mods in game, mods are not bannable but just use this wisely. 
# Instructions 
- Follow these instructions directly to ensure that the mod installation process is as smooth as possible 
# Step 1:
- Download the "step1.unzip" file or the UTOC Signature Bypass from NexusMods, and then unzip the file.
  - If you do not know how to unzip a file, here is a tutorial!:
    - [How to unzip a file on Windows 10/11](https://www.youtube.com/watch?v=HLBSS3JjAh0)
- Take the 'Plugins' Folder and 'dsound.dll' and drop into the set of folders at this location: C:\Loading Bay Games\Marvel Rivals\MarvelGame\Marvel\Binaries\Win64
  - This location can be found by going to 'Check local files' by clicking on the gear on Steam, or by clicking 'Check Files' in the Loading Bay launcher by clicking on the 3 lines next to 'start game'
  - This 'Loading Bay Games\' folder is for NetEase, but the '\Marvel Rivals\MarvelGame\Marvel\Binaries\Win64' will be the same for pretty much every other launcher

# Step 2:
- Go to the file location: ==C:\Loading Bay Games\Marvel Rivals\MarvelGame\Marvel\Content\Paks==, or replace the 'Loading Bay Games' with 'Steam' or another launcher, which ever you use!
- Next, right click inside the file explorer and click 'New' then 'Folder'
- You will now name this folder 'mods' or '~mods'
  - The " ~ " symbol puts it at the top of the folder so it makes it a little easier to find when you want to add mods
- Have Fun! You can now use mods inside Marvel Rivals by dragging and dropping the ".pak" files you get off of NexusMods or any other mod platform
  - [Link to Marvel Rivals Mods on NexusMods](https://www.nexusmods.com/games/marvelrivals/mods)
  - Some older mods may not work as well or may not be updated, which could cause them to not work in game
  - I would recommend using mods created fairly recently as they will most likely work with no issues
